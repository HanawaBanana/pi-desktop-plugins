# session-import has moved

This plugin now lives in its own repository:

- **Source:** [muzimu217/pi-desktop-session-import](https://github.com/muzimu217/pi-desktop-session-import)
- **Install:** [Plugin Center — io.github.muzimu217.session-import](https://plugins.aiuo.net/) (the client's default marketplace)

Per the maintainers' direction (vastsa/pi-desktop-plugins#56), all import
features — sessions, and later model configs, external MCP and skills — are
being absorbed into the plugin, and the host's built-in Import page will be
retired once the plugin reaches parity. Development, issues and releases
happen in the standalone repository; releases are published on the plugin
center, not from this monorepo.
