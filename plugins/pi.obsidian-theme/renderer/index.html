Obsidian Theme

Deep blue-grey · teal accent

About

This plugin contributes one global theme (CSS only) and nothing else. Apply it in Settings → Theme and search Obsidian.

Apply & revert

  1. Open Settings → Theme and search Obsidian.
  2. Pick Obsidian Dark. The whole app repaints instantly.
  3. To revert, choose Light, Dark or System — the plugin can stay installed with no effect.
